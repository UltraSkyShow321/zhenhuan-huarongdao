逃出深宫

玩法说明

1. 经典华容道：棋子只能沿空格滑动，每次一格。
2. 目标：把 2×2 的「甄嬛」移到最下方宫门口。
3. 操作：点选棋子后拖动，或用键盘方向键 / 屏幕方向钮移动。
4. 卡关可点「提示」或按 H：显示最优走法的下一步与距通关步数。
5. 步数越接近「参考步数」，星级越高；Z 悔棋，R 重开。

💾 存档管理

导出存档码保存好（发给自己/网盘），换设备或重装后粘贴导入即可恢复全部进度。

📱 安装到你的设备

🍎 iPhone / iPad（iOS / iPadOS）

  1. 用 Safari 打开在线版链接
  2. 点底部「分享」按钮（方框向上箭头 ↑）
  3. 列表中选「添加到主屏幕」→ 添加
  4. 桌面出现「深宫华容道」图标，点开即全屏游玩，支持离线

原生 App 需要 Apple 开发者账号与 Mac 构建，仓库已附 Capacitor iOS 工程接入说明（见 mobile/IOS.md），有条件的可自行打包。

🤖 Android / 鸿蒙 1-4

  1. 到 GitHub 仓库 Releases 页下载 .apk
  2. 允许「未知来源应用」安装

⭕ 纯血鸿蒙 6.0+

  1. 浏览器打开在线版 → 菜单「添加到桌面」即可游玩（离线可用）
  2. 原生 HAP：仓库 mobile/harmonyos/ 为完整 ArkTS 工程，用免费 DevEco Studio 约 5 分钟构建安装（附详细指南）

🖥 Windows / macOS / Linux

  1. 到 GitHub 仓库 Releases 页下载对应安装包（Windows 推荐 zip 版）
  2. Windows：Setup 安装版 / Portable 免安装 / ZIP 解压即玩
  3. macOS：按芯片选 arm64（M 系列）或 x64（Intel）的 dmg
  4. Linux：AppImage（chmod +x 后运行）或 .deb
